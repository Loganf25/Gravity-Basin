
This is a gravity simulation program that allows the user to visualize our solar systems planets, and witness the gravity interactions that can occure within.

## Run
Check your dependencies, and download any you are missing
IDE run method:
```bash
Clone this into your IDE: https://github.com/Loganf25/Gravity-Basin.git
Run the runner file located at Gravity-Basin/src/main.py
```
Command Line run method:
```bash
Download this github repo into a designated folder: https://github.com/Loganf25/Gravity-Basin.git
go to your_folder/Gravity-Basin/src/main.py and copy its absolute file path
paste the file path into your Command Line and press enter, it should start running
```
Executable Run method (should not require any dependencies for this one)[unstable]:
```bash
Download this github repo into a designated folder: https://github.com/Loganf25/Gravity-Basin.git
go to your_folder/Gravity-Basin/src/dist and find the only .exe file and run it
```
